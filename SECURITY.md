# Security policy

Report vulnerabilities in Mangudai (mangudai.io) to **support@mangudai.io** with the subject "Security report". Include the affected URL, steps to reproduce and the impact. Please do not test against other customers' data, run denial-of-service tests or publish details before a fix is available. We acknowledge reports and fix confirmed issues as quickly as we can.

Mangudai also publishes a machine-readable policy at https://mangudai.io/.well-known/security.txt.
